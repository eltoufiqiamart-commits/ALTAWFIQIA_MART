# دليل لوحة الإدارة — EL TAWFIKIA MART

الوصول من `/admin` بعد تسجيل الدخول بحساب له دور إداري. لا يوجد رابط للوحة في
الواجهة العامة، والحماية الحقيقية قائمة على الصلاحيات وRLS وليس إخفاء الرابط.

## الأقسام

| الصفحة | الوظيفة |
|---|---|
| الرئيسية | إيراد 30 يومًا، ربح الطلبات المسلّمة (التكلفة خاصة)، طلبات اليوم، دفعات قيد المراجعة، تنبيهات المخزون، آخر الطلبات |
| المنتجات | بحث/تصفية، إضافة وتعديل، الحالة (منشور/مسودة/مؤرشف)، رفع صور متعددة، توافق السيارات، استيراد/تصدير CSV |
| المخزون | الكلي/المحجوز/المتاح، حد إعادة الطلب، تسويات ذرّية عبر `adjust_stock` مع تسجيل السبب |
| الأقسام / الماركات | إضافة وتعديل وأرشفة (soft delete) |
| السيارات والتوافق | شجرة ماركة → موديل → سنة → محرك |
| المورّدون | **خاص** بمن لهم الصلاحية: أسماء وهواتف وتكلفة المخزون الحالية |
| الطلبات | بحث برقم الطلب/الاسم/الهاتف، تصفية بالحالة/الدفع، تتبع التدبير لدى المورّد |
| دفعات قيد المراجعة | عرض الإيصال برابط موقّت، تأكيد أو رفض التحويل اليدوي |
| المرتجعات | موافقة/رفض/استلام/رد المبلغ وفق الحالات القانونية (14 يومًا) |
| العملاء | بيانات العملاء وطلباتهم، وإيقاف الحساب/تعيين الأدوار (للمدير العام فقط) |
| رسائل التواصل | صندوق وارد لرسائل صفحة "اتصل بنا" مع تعليمها كمُرد عليها (مدير الطلبات وخدمة العملاء) |
| الكوبونات | نسبة (بنقاط الأساس) أو خصم ثابت، حدود الاستخدام، فترات السريان |
| التقييمات | اعتماد/إخفاء مراجعات المشترين الموثّقين |
| المحتوى والبانرات | رفع بانرات WebP وإدارة أقسام الصفحة الرئيسية واختيار منتجاتها |
| التحليلات | الإيراد اليومي، طرق الدفع، المحافظات، الأكثر مبيعًا، عبارات البحث بلا نتائج |
| سجل التدقيق | سجل غير قابل للتعديل لكل العمليات الحساسة |
| الإعدادات والشحن | رسوم الشحن والمواعيد لكل محافظة؛ نسب الخصم للقراءة فقط |

## قواعد عمل مهمة (مفروضة خادميًا)

- كل الأسعار تُحسب على الخادم؛ لا يُوثق بسعر أو كمية أو كوبون قادم من المتصفح.
- رسوم الدفع عند الاستلام **1% بالضبط**، وخصم الدفع المسبق **3% تحت 3000 ج.م
  و5% فوقها**؛ شاشة الإعدادات تعرضها للقراءة فقط.
- المخزون يُحجز ذرّيًا لحظة إنشاء الطلب، ولا يُخصم من المتاح إلا عند التسليم؛
  الإلغاء يفك الحجز فورًا.
- التكلفة واسم المورّد لا يُختاران إلا لمن يملك `products.cost.view` أو
  `suppliers.read`، ولا يظهران في أي مسار عام حتى لو أُنشئت صفحة خطأً.
- رفع الصور عبر `/api/uploads/product` و`/api/uploads/content` فقط، مع فحص
  الملف بـ magic bytes وإعادة ضغط WebP (حد 5 ميجابايت).
- إيصالات الدفع في Bucket `private` ولا تُعرَض إلا برابط موقّع قصير العمر، حصريًا
  لمن يملك صلاحية `payments.verify` (مدير الطلبات والمدير العام).
- كل عملية كتابة تُسجَّل في سجل التدقيق مع دور المُنفِّذ الحقيقي: المنتجات
  والصور والمخزون والكوبونات والأقسام والماركات والسيارات والمورّدين والبانرات
  وأقسام الرئيسية ورسوم الشحن ورسائل التواصل وتعيينات الأدوار، إضافة إلى
  عمليات تصدير CSV (تُسجَّل بصفتها وصولًا للبيانات).
- الطلب المدفوع مسبقًا الذي لا تصل عنه حوالة خلال 24 ساعة يُلغى تلقائيًا
  (مهمة `/api/cron/maintenance`)، ويُفرج عن مخزونه ويُعاد كوبونه؛ لا ينطبق هذا
  على الدفع عند الاستلام ولا على الدفعات التي أُرسل عنها إيصال قيد المراجعة.

## حالات الطلب

`pending → confirmed → processing → ready_for_shipment → shipped →
out_for_delivery → delivered`، مع مسار الإرجاع
`return_requested → return_approved → returned → refunded`.
الانتقالات المسموحة مقيّدة في دالة `admin_transition_order` بقاعدة البيانات،
ولا تستطيع الواجهة تجاوزها.
