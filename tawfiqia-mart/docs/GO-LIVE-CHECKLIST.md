# قائمة الإطلاق النهائية — EL TAWFIKIA MART

وثيقة تشغيلية واحدة تُنفَّذ بالترتيب. كل بند إما **مكتمل** (تم التحقق منه في
بيئة التطوير) أو **مطلوب منك** (لا يمكن إنجازه بدون مشروع Supabase حي أو حساب
Vercel). لا تُطلق قبل إنهاء القسمين 2 و3.

## 0) مكتمل ومُتحقَّق منه بالفعل (لا إجراء مطلوب)

- [x] `npm run typecheck` / `lint` / `lint:admin` / `build` كلها تنجح على بناء
      نظيف **بدون أي ملف .env**.
- [x] `npm audit --omit=dev` = 0 ثغرات.
- [x] صفر أسرار أو JWT أو `service_role` داخل حزم المتصفح (`.next/static`).
- [x] مصفوفة الجوال 320→1920: صفر تمرير أفقي، `dir=rtl` و`lang=ar` دائمًا.
- [x] فحص الوصولية على 19 صفحة عامة: صفر ملاحظات.
- [x] أهداف اللمس ≥ 36px على كل عناصر التنقل.
- [x] خرائط الموقع (فهرس + صفحات + شظايا منتجات) تُرجع XML صحيحًا.
- [x] ترويسات الأمان (CSP، HSTS، X-Frame-Options، nosniff، Permissions-Policy).
- [x] صفر إيموجي في الكود، ولا وعد بتوصيل مضمون خلال 24 ساعة في أي نص.

## 1) إعداد Supabase (مطلوب منك)

- [ ] أنشئ مشروعًا جديدًا (اختر أقرب منطقة: `eu-central-1` أو `eu-west-3`).
- [ ] طبّق الترحيلات **بالترتيب 0001 → 0019** من `supabase/migrations/`
      عبر SQL Editor أو `supabase db push`.
- [ ] أنشئ الـ Buckets:
  - `products` — **عام** (public).
  - `private` — **خاص** (private) للإيصالات.
- [ ] Authentication → URL Configuration:
  - Site URL = رابط الإنتاج.
  - Redirect URLs = `https://<domain>/auth/confirm` و`https://<domain>/**`.
- [ ] Authentication → Providers → Email: فعّل تأكيد البريد، واضبط SMTP حقيقيًّا
      (بريد Supabase الافتراضي محدود جدًّا ولا يصلح للإنتاج).
- [ ] أنشئ أول حساب مالك: سجّل عبر الموقع ثم نفّذ:
      `update public.profiles set role = 'super_admin' where id = '<your-uuid>';`
      (الأدوار الفعلية في النظام: `super_admin`, `product_manager`,
      `order_manager`, `content_manager`, `customer_support`, `customer` —
      لا يوجد دور باسم `owner`.)

## 2) اختبارات الأمان الحية — **البند الأهم، لا إطلاق بدونه**

- [ ] أنشئ حسابَي عميل اختباريين مختلفين (A و B)، ونفّذ بحساب A طلبًا واحدًا
      على الأقل مع رفع إيصال، حتى تكون هناك بيانات فعلية للعزل.
- [ ] احصل على معرّفيهما:
      `select id, email from auth.users order by created_at;`
- [ ] جهّز الملف:
      ```bash
      node scripts/prepare-security-tests.mjs <A_UUID> <B_UUID>
      ```
      ينتج `docs/SECURITY-TESTS.ready.sql` (مستثنى من git لأنه يحمل معرّفات حقيقية).
- [ ] الصقه في SQL Editor ونفّذه من أوله لآخره. كل جزء داخل معاملة تُلغى
      (rollback) فلا يتغير أي بيان.
- [ ] **الشرط**: كل صفوف النتائج تقرأ `PASS`. أي `FAIL` يُعالَج قبل الإطلاق.
- [ ] احذف `docs/SECURITY-TESTS.ready.sql` بعد الانتهاء.
- [ ] أعد تشغيل هذه المجموعة بعد أي تعديل مستقبلي على RLS أو دوال RPC.

## 3) نشر Vercel (مطلوب منك)

- [ ] اربط المستودع، واضبط **Node.js Version = 22.x** في إعدادات المشروع.
- [ ] متغيرات البيئة (راجع `.env.example`):
  - `NEXT_PUBLIC_SUPABASE_URL`
  - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  - `SUPABASE_SERVICE_ROLE_KEY` — **Production فقط، لا تضعه في أي متغير
    يبدأ بـ NEXT_PUBLIC**
  - `NEXT_PUBLIC_SITE_URL` — رابط الإنتاج الكامل
  - `CRON_SECRET` — سلسلة عشوائية طويلة (`openssl rand -hex 32`)
- [ ] تحقق أن `vercel.json` فعّل الكرون اليومي `/api/cron/maintenance` (0 1 * * *).
- [ ] بعد أول نشر، اختبر يدويًّا: `curl -I https://<domain>/api/cron/maintenance`
      يجب أن يُرجع **401** بدون السر.

## 4) فحص ما بعد النشر (15 دقيقة)

- [ ] الصفحة الرئيسية تُحمَّل، الشعار وصورة الهيرو تظهران بوضوح.
- [ ] `https://<domain>/sitemap.xml` يُرجع فهرسًا و`robots.txt` سليم.
- [ ] `/admin` و`/account` و`/checkout` تعيد التوجيه لتسجيل الدخول عند عدم الدخول.
- [ ] حساب عميل غير مصرح يفتح `/admin` → صفحة 403.
- [ ] **رحلة شراء كاملة على الإنتاج**: إضافة للسلة → دفع → إنشاء طلب →
      رفع إيصال → موافقة الإدارة → تغيير الحالة حتى «تم التسليم» → طلب إرجاع.
- [ ] تحقق أن رابط الإيصال الموقّع ينتهي بعد 10 دقائق، وأن العميل لا يستطيع
      فتح إيصال عميل آخر.
- [ ] راجع `audit_logs` وتأكد أن كل عملية إدارية سُجِّلت بالدور الحقيقي.
- [ ] افحص أدوات المطور: لا أخطاء CSP، ولا طلبات لنطاقات خارجية.
- [ ] Lighthouse على الجوال للصفحة الرئيسية وصفحة منتج.

## 5) قرار مطلوب من المالك

- [ ] **صورة الهيرو `photo1`** تحتوي نصًّا مضمَّنًا داخل الصورة:
      «توصيل في أقل من 24 ساعة». هذا يخالف الصياغة المعتمدة
      («توصيل سريع، وتختلف مدة التوصيل حسب الموقع وظروف الطلب») وقد يُعدّ
      وعدًا تجاريًّا غير قابل للوفاء. لم تُعدَّل الصورة التزامًا بتعليمة
      «استخدمها كما هي». الخيارات: (أ) إعادة تصميم الصورة بنص مطابق للسياسة،
      (ب) قصّ/إخفاء الشريط النصي، (ج) الإبقاء عليها بقبول المخاطرة.
