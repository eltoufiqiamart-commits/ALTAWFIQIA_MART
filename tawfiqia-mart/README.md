# التوفيقية مارت — EL TAWFIKIA MART

متجر إلكتروني عربي (RTL، أولوية الجوال) لقطع غيار السيارات، مبني على **Next.js 14 (App Router)** و**Supabase** (Postgres + Auth + Storage) وقابل للنشر مجانًا على Vercel + Supabase Free.

## المميزات

- واجهة عربية بالكامل `dir="rtl"`، تصمم أولًا للجوال (320–414px) ثم الشاشات الأكبر.
- بحث سيرفر-سايد عبر Postgres FTS + Trigram مع تطبيع للعربية، ترقيم صفحات، واقتراحات بحث.
- شجرة سيارات: ماركة → موديل → سنة الصنع → المحرك، مع توافق المنتجات.
- سلة وطلبات مع **لقطة أسعار ثابتة غير قابلة للتغيير**، حجز مخزون ذرّي، ومفاتيح Idempotency.
- إلغاء تلقائي يومي (Vercel Cron) لطلبات الدفع المسبق التي لا تُدفع خلال 24 ساعة مع إفراج الحجز وإعادة الكوبون، خلف نقطة `/api/cron/maintenance` محمية بـ`CRON_SECRET`.
- محرك تسعير مركزي: رسوم COD **1% بالضبط**، خصم الدفع المسبق **3% تحت 3000 ج.م و5% فوقها**، كوبونات، شحن حسب المحافظة.
- دفع يدوي: فودافون كاش / إنستا باي / تيلا-فوري + الدفع عند الاستلام، مع إيصالات تُحفظ في Bucket خاص.
- إرجاع خلال 14 يومًا، تقييمات من مشترين موثّقين فقط، قائمة مفضلة (تتطلب دخولًا).
- لوحة إدارة بصلاحيات أدوار: مدير عام، مدير منتجات، مدير طلبات، مدير محتوى، خدمة عملاء.
- المورّدون والتكلفة والأرباح **بيانات خاصة تمامًا** لا تظهر في أي استعلام عام.
- سجل تدقيق، تحليلات، استيراد/تصدير CSV، رفع صور بفحص magic-bytes وإعادة ضغط WebP.
- RLS شامل، Security Headers، Rate limiting قائم على قاعدة البيانات (يعمل على Serverless بلا ذاكرة).

## الأدوار والصلاحيات

تُدار بالكامل من الخادم وملف `src/lib/permissions.ts`، وتُفرض ثانيةً داخل Postgres عبر `has_permission()`. لا يعتمد الأمان على إخفاء الروابط.

| الدور | الصلاحيات الأساسية |
|---|---|
| المدير العام (`super_admin`) | كل شيء، وإدارة أدوار الموظفين |
| مدير المنتجات | المنتجات، المخزون، الأقسام/الماركات/السيارات، المورّدون، المحتوى، التحليلات |
| مدير الطلبات | الطلبات، تأكيد الدفعات، المرتجعات، العملاء، قراءة المورّدين |
| مدير المحتوى | الأقسام، الماركات، البانرات وأقسام الصفحة الرئيسية |
| خدمة العملاء | قراءة الطلبات/العملاء وإدارة المرتجعات |

أول مدير عام يُسجَّل بريده في `SUPER_ADMIN_EMAILS`، ثم تُدار بقية الأدوار من `/admin/customers`.

## البدء محليًا

```bash
npm install
cp .env.example .env.local   # املأ قيم Supabase
# طبّق الترحيلات مرة واحدة (راجع docs/DEPLOYMENT.md للتفاصيل)
npm run dev
```

## الفحوصات قبل النشر

مشروع النوع مقسّم إلى ثلاث حزم تتناسب مع بيئات RAM الصغيرة (~2GB):

```bash
npm run typecheck    # shop + admin-a + admin-b
npm run lint         # الواجهة
npm run lint:admin   # الإدارة والـ API
npm run build        # بناء الإنتاج
npm run verify       # typecheck + lint + build
```

## بنية قاعدة البيانات

- `supabase/migrations/` — ترحيلات مرقّمة تُبنى على قاعدة فاضية بالترتيب (0001 → 0015).
- `supabase/seed-demo.sql` — **اختياري**، بيانات تجريبية (منتجات/توالف/كوبون) وليس ترحيلًا.
- المال كله أعداد صحيحة بالقروش (Piastres)، لا كسور.
- Soft delete للمنتجات/الأقسام/الماركات/المورّدين، والطلبات والماليات سجل ثابت غير قابل للتعديل.
